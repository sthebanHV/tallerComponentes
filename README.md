# TallerComponentes

Diagramas de **componentes UML** (vista funcional) generados con **Visual Paradigm 18.1** para el taller, cubriendo dos casos:

| Caso | Contenido | Archivos |
|------|-----------|----------|
| **MediCare** | 6 componentes y 6 dependencias justificadas ("frase guía" en cada una) | `MediCare/MediCare.vpp` + `MediCare/MediCare.png` |
| **EduManager** | 5 componentes y 5 dependencias justificadas | `EduManager/EduManager.vpp` + `EduManager/EduManager.png` |

## Cómo usar

- **PNG**: vista previa lista para revisar o entregar.
- **VPP**: abrir con Visual Paradigm → `File > Open Project` para ver o editar el modelo (tipo de diagrama: *Component Diagram*).

## Notas

- Cada dependencia es una línea discontinua con flecha del cliente al proveedor, etiquetada con la frase que la justifica.
- Los PNG incluyen la marca de agua de la versión de evaluación de Visual Paradigm.
